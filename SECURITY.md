# Security reports

TIZY is experimental. Reports for 0.14.4 are welcome, but no fix deadline or support for all firmware is promised.

Do not publish a vulnerability with exploitable reproduction steps in an issue. Use **Security → Advisories → Report a vulnerability** when private vulnerability reporting is enabled. If a private channel is unavailable, ask for one without disclosing exploit details. Do not send keys or certificates.

Include affected version/component, conditions and likely impact. Live servers, UUIDs, subscriptions, serial numbers and access to your TV are not needed.
