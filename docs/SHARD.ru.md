# TIZY Shard 0.4.3

Самостоятельный VPN-плагин для Vetro 0.5.0 / Shards API 1. Управление находится
в Vetro → Shards → TIZY. Отдельный пакет TIZY WGT, его интерфейс, служба,
локальное HTTP API, SDB-соединение и работающий компьютер не нужны.
Vetro и его root-agent должны работать на телевизоре.

## Установка

1. Откройте панель Vetro → Shards → установка из файла.
2. Включите Developer mode, выберите `tizy-0.4.3.vplugin`, включите TIZY.
3. Вкладка TIZY → Серверы: добавьте ссылки/HTTPS-подписку. Если установлен
   старый TIZY, кнопка переноса скопирует серверы, выбранный сервер и настройки
   в пустой список. Старые данные не удаляются.
4. Отключите другое VPN-соединение на ТВ. Нажмите кнопку питания во вкладке
   «Главная». При первом подключении ядро загружается автоматически.
5. После подключения вкладку и компьютер можно закрыть. Vetro должен оставаться
   запущенным. Автоподключение действует при запуске службы Vetro с включённым
   плагином; root после загрузки обеспечивает сам Vetro.

## Возможности

- VLESS / Reality / XHTTP, VMess, Trojan, Shadowsocks; ссылки и HTTPS-подписки.
- Серверы IPv4 / IPv6, выбор типа IP; до 200 серверов.
- Перенаправление TCP IPv4 приложений, DNS через VPN; блокировка внешнего
  UDP / IPv6 от обхода VPN; домашняя сеть напрямую. Это не туннель UDP/IPv6.
- Включение VPN только для выбранных приложений либо исключение приложений.
- Счётчики Xray, скорость, длительность подключения; журнал без паролей.
- Проверка туннеля каждые 30 секунд и переподключение после потери связи.
- До трёх попыток автоподключения. Ручное отключение приостанавливает его
  до ручного подключения, изменения настройки или перезапуска плагина.
- Остановка плагина удаляет его правила; watchdog восстанавливает сеть при
  потере lease службы (обычно до 20 секунд после аварийного завершения).

QR-приём поддерживает Incy, Happ и v2RayTun. Геофлаги и замер пинга
не перенесены. Настройки старого клиента сохраняются, язык интерфейса выбирается в разделе «Язык»: Русский, English, Türkçe,
简体中文 или автоматический выбор по языку браузера/телевизора. HTTPS-подписки загружаются по IPv4; сами VPN-серверы поддерживают IPv6.
Отключение плагина сохраняет настройки; удаление из Vetro удаляет его config.json.

## Ядро и данные

Пакет содержит только текст, укладывается в лимит API 1 (20 файлов / 512 КБ).
Немодифицированный Xray 26.10.31 (ARMv7 / ARM64) загружается с опубликованного
репозитория mxbforge/tizy по зафиксированному commit
`76d1b94b2495f5e475e20086102677e3e59ebdde`. Перед запуском проверяется SHA-256:

- ARMv7: `2a893d5b5f7cf5a33168c102f01771ed69a674abeab0b8fb085b1ddf098cf52c`
- ARM64: `5939649960deaf535bcd5f7ce0467a2b1d63b72a2758a6f42eade714ae8d5328`

Бинарник и временные рабочие файлы: `/opt/usr/home/owner/share/tizy-shard-data`.
Серверы и настройки: только `config.json` плагина (0600), который сохраняет
Vetro при обновлении. Проверенный бинарник запускается через временный
read-only bind mount `/opt/usr/home/owner/share/tizyp-runtime-uep/ro`.
Прошивка и загрузчик не изменяются. Порты 20053, 20080–20082, 20085; только loopback.
Плагин использует собственные TIZYP_* chains / cgroups и не удаляет правила WGT.
Одновременное использование нескольких VPN не поддерживается.

Исходники TIZY — MIT, Xray — MPL-2.0, ipaddr.js 1.9.1 — MIT. Лицензии приложены.

## Сборка и проверки

Из корня репозитория:

```
node scripts/plugin-tools/scripts/vetro-plugin.cjs check plugins/tizy
node scripts/plugin-tools/scripts/vetro-plugin.cjs pack plugins/tizy dist
node tests/plugin.cjs
node tests/plugin-ui.cjs
```

Инструмент упаковки и валидатор взяты из Vetro release-0.5.0 без изменений:
https://github.com/andrearicci93/vetro/tree/release-0.5.0/app

Аппаратная проверка выполняется на Samsung QE50QN90AAUXRU / Tizen 6,
ARMv7 / Node 12.4.0. Factory, start/stop/restart, UI и три QR-протокола
проверены отдельными процессами Node 4.4.7, 12.4.0 и 20.19.0 на macOS.
ARM64 и старые модели ТВ требуют отдельной аппаратной проверки.
Все модули, включая встроенные строки и загружаемую криптографию, используют ES5.

## Добавление серверов 0.2.0

Кнопка «+ Добавить» справа от основных разделов открывает экран, как в TIZY:
QR слева, ссылка/подписка справа. В разделе «Серверы» остался только список.
Перенос из старого приложения доступен в «Настройки → О приложении».

QR появляется только после готовности приёмника. Incy использует регистрацию
восьмисимвольного кода и шифрованную передачу через официальный релей;
Happ — TCP в домашней сети; v2RayTun — официальный WebSocket-релей.
Код действует пять минут. Выход с экрана и остановка плагина закрывают приём.
Поздние результаты отменённой передачи не импортируются.

При первом открытии QR загружаются libsodium-sumo / wrappers 0.7.9 с CDN npm
(jsDelivr). Каждый файл проверяется по SHA-256, зафиксированной в qr-runtime.js,
и сохраняется только на ТВ. Ключи и адреса ваших серверов CDN не получает.
WebSocket и генератор QR включены в плагин; отдельный TIZY WGT не нужен.
QR совместим с Node 4.4.7; WebSocket 5.2.4 собран в ES5, Buffer-совместимость
ограничена модулями плагина и не изменяет глобальные объекты Vetro.

Зависимости сборки: `npm ci --prefix scripts/plugin-deps --ignore-scripts`.
Сборка протоколов: `node scripts/build-plugin-pairing.cjs`, затем стандартный pack.
Живые тесты: `npm run test:plugin:pairing:live` — только синтетические данные.

## Управление и маршрутизация 0.3.0

Для режимов «Напрямую» и «Через VPN» показано отдельное пояснение. Включение,
отключение и выбор приложений применяются только кнопкой «Сохранить», включая
активное VPN-подключение. Xray при этом не перезапускается; при ошибке правила
возвращаются к прежней конфигурации. Уведомление об успехе исчезает через 3 секунды.
Несохранённый выбор сохраняется при переключении режимов в интерфейсе.

Время: ММ:СС до 59:59, затем ЧЧ:ММ:СС, с обновлением каждую секунду.
В «Серверах» отображается количество записей. Удаление находится в меню ⋮.
Кнопка Ping запускает проверку всех серверов (до трёх одновременно); справа
от меню показывается время TCP-подключения в миллисекундах. Это TCP-замер,
а не ICMP и не проверка полного VPN-туннеля. При активном VPN замер выполняется
из сетевой группы Xray, чтобы измерить прямой путь до сервера. Список и порядок
серверов Ping не меняет. При остановке плагина проверки отменяются.

## Журнал и экспорт (0.4.2)

Как в приложении TIZY: запись событий, уровни, категории, подробности, счетчик и очистка.
Журнал хранит до 300 событий в памяти, настройки — в `ctx.config`. Ссылки и ключи скрываются.
Экспорт — UTF-8 TXT, весь журнал или выбранные фильтры, без QR-кода.

Стандартная песочница Vetro 0.5.0 (`allow-scripts`, без `allow-downloads`) запрещает
автоматическое скачивание из вкладки. «Экспорт журнала» показывает ссылку на файл:
скопируйте её и откройте в адресной строке браузера компьютера. Браузер скачает TXT.
Ссылка содержит ограниченный токен сессии плагина; не передавайте её посторонним.
Она истекает через 8 часов или после выключения плагина. Vetro не изменяется.
